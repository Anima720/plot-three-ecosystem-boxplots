# 图形与交付契约

## 主图

- 每个指标一个坐标面板，线性纵轴。
- 图层包含箱体、全部抖动原始点、红色算术均值菱形和红色均值虚线。
- 固定配色：
  - Meadow：`#D97A73`
  - Steppe：`#D8B74F`
  - desert：`#65AFA2`
- 三个固定组对全部显示比较括号，不因不显著而隐藏。
- 括号标签使用正式分支的调整后 P：`Tukey p`、`GH p`、`HC3-Holm p` 或 `Dunn-BH p`。
- 面板方法文字分别为 `ANOVA + Tukey HSD`、`Welch ANOVA + Games-Howell`、`HC3 robust F + HC3 contrasts (Holm)` 或 `Kruskal-Wallis + Dunn (BH)`。
- 图中显示同类指标总体 BH 校正后的 `q(BH)`；多重比较字母置于各组数据上方。
- 坐标轴、括号、字母和标题必须留出空间，使用 `coord_cartesian(clip = "off")`，禁止裁切。

## 尺寸与版式

- Cairo 矢量 PDF，主图单页。
- 每个 ggplot 坐标面板的内部边框绝对尺寸为：宽 `263.645 pt`，高 `222.34 pt`。
- 指标按配置顺序排列，每行最多 3 个面板；行数随指标数自动增加。
- 总图尺寸由固定面板 grob 的实际宽高计算，不靠手工猜测。
- 残差 Q–Q 诊断 PDF 同样单页、动态网格，每个指标展示合并线性模型残差、参考线和 Shapiro P。
- 图题和坐标优先使用英文，避免 PDF 字体兼容问题；统计表和方法说明使用中文。

## 七工作表 Excel

顺序与名称固定：

1. `分析总览`
2. `两两比较`
3. `描述统计`
4. `模型诊断`
5. `残差诊断`
6. `异常值标记`
7. `方法与质控`

数值以完整精度写入，不在数据层提前格式化。Excel 仅设置显示格式；不得用公式代替已核验数值。必须重开、核对表序与行数、扫描公式错误，并逐张渲染预览；Codex 还须实际查看全部预览，检查列宽、换行、裁切和乱码。

## 最终目录

每批建立新的、有意义且带日期或版本的输出目录，不覆盖历史结果。最终目录至少包含：

- `<stem>_箱线图总图.pdf`
- `<stem>_残差Q-Q诊断.pdf`
- `<stem>_统计分析汇总.xlsx`
- `<stem>_绘图与统计分析_残差诊断四分流.R`
- `<stem>_分析配置.json`

七表 JSON、Excel 预览、构建报告、渲染 PNG 和审计日志放在配置的临时目录，不进入最终交付目录。

启动器和交付 R 脚本都会拒绝含非本流程文件、子目录或不同批次配置的既有输出目录。仅允许当前批次由首轮 `expected_branches=null` 升级为锁定分支，以及同一配置的确定性重跑；这不等于允许覆盖历史结果。
