# 数据契约

## 研究设计边界

- 固定三个独立处理组：`Meadow`、`Steppe`、`Desert`。
- 仅在内存和图表中把 `Desert` 或 `desert` 统一显示为 `desert`。
- 不允许把站点内子样、同一样方重复测量、批次重复或技术重复冒充独立重复。
- 如果存在配对、区组、嵌套、重复测量或其他层级结构，本工作流不适合作为最终推断。
- 当前研究体系已明确按三个独立生态系统处理组分析时可以执行；缺少样本 ID 只表示无法逐行核验身份，不能单独据此断定观测不独立。

## 源文件原则

1. 源 Excel 始终只读，不回写、不另存、不插补、不四舍五入、不重排。
2. 运行前后均计算整个源文件的 SHA256，必须完全一致。
3. 先检查工作表名称、标题行、合并单元格、装饰行、单位和真正的数据范围。标题在首行时用 `input_skip=0`；标题前有装饰行时用精确 `input_skip`；需要截取矩形区域时用包含标题行的 `input_range`。两者不得冲突；若范围写有工作表前缀，该前缀必须与 `input_sheet` 完全一致。
4. 分组列只接受 `Meadow`、`Steppe`、`Desert`/`desert`，其他拼写直接报错。
5. 请求指标必须为数值列且全部为有限值；发现缺失或非有限值时停止，不得静默完整案例筛选。
6. 重复值不自动删除。是否为真实生物学重复必须依据样本 ID 和试验设计判断。

## 指标列选择

- 用户明确列出指标时，仅按精确源列名和给定顺序分析，不做近似匹配。
- 用户要求“全部指标”且工作表是专用指标表时，默认选择除分组列、样本/站点/样方/重复编号和结构元数据外的全部有限数值响应列，顺序沿用源表。
- 经纬度、深度、日期/时间、处理剂量、测序深度、覆盖度、质控量等数值列可能是协变量或元数据，不能因为是数值型就自动作为响应指标。
- 若某列用途无法从表头、单位和研究上下文唯一判断，先输出候选指标与拟排除字段清单，只针对这些歧义列请求一次确认；在确认前不得运行统计分析。

## 样本追踪

- 有样本 ID 列时，验证无缺失、无空白且唯一，并保留到异常值表。
- 无样本 ID 时，用真实 Excel 源行号生成 `SourceRow_*` 追踪标识；源行号必须随 `input_skip` 或 `input_range` 的标题行位置变化，并在“方法与质控”中记录无法验证行级身份与独立性的限制。
- 配置中的 `expected_group_counts` 必须来自只读盘点结果，三个组逐一锁定。

## 指标与派生值

- 源表已有指标、比值或百分数必须直接读取现有单元格，不重新计算、不缩放、不补百分号。
- 仅当用户明确要求且源表没有该指标时，才使用 `derived_metrics` 在内存逐行派生。
- 允许的可审计运算：`sum`、`difference`、`ratio`、`product`；`difference` 和 `ratio` 的顺序由 `columns` 明确决定。
- 比值分母含 0、派生结果缺失或非有限时停止。
- 派生值不得写回源文件；统计表“源列”必须记录派生公式。

示例：

```json
"derived_metrics": {
  "Total biomass": {
    "operation": "sum",
    "columns": ["样方地上生物量", "root biomass"]
  }
}
```

## 输入验收记录

至少记录：绝对路径、工作表、标题行/读取范围、源 SHA256、分组列、样本 ID 列或缺失说明、每组 n、指标源列、已知单位或“单位未提供”、缺失数、非有限数、派生规则以及潜在层级结构风险。不得根据指标名称自行补单位。
